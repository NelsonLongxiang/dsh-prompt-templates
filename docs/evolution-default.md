# Atelier 演化自评估：默认会话模板 v2（0.15.0 起随插件发布）

## 合同

本插件仅在已有 `agent/pre-step` 轮次注入通道补充提示词，不执行评估、训练模型、迁移目录、授权、安装、部署或 A2A 成员操作。Atelier 负责方法论；A2A Net 负责其角色/身份/规则约束；业务成果、反馈和价值决定是否演变，不是满 100 轮就升级。

- 方法论：[演化自评估固定参考](https://github.com/NelsonLongxiang/agent-atelier/blob/6278996da228eccc83843b12b8e93b6c4a13e9c9/references/evolution-self-assessment.md)，配套 Atelier #61 已合并。本轮本机已安装 Atelier 5.16.0 中可以读取该参考；文件存在不等于任意宿主已加载技能或模型已执行。
- 身份治理：[dsh-open-a2a-net](https://github.com/NelsonLongxiang/dsh-open-a2a-net)。仅实际 Super Agent 身份适用其角色规范；角色规则变更遵循 `propose → owner 后续亲自消息确认 → apply`，成员操作按来源及逐操作授权另核，不把规则确认流程泛化到所有成员操作或已授权本地改进。提醒不扩大授权。
- 实现：`src/evolution-default.ts` / `src/store.ts` / `src/inject.ts`。

## 自动补充与优先级

默认 `evolutionAssessmentEnabled: true`。同时需 `injectEnabled: true`；任一关闭不自动补充。每个会话首次获准的非空 pre-step，事务内检查并补一份可见会话模板 `工坊·演化自评估`，默认每 100 **用户轮次**，非工具调用/模型 step/时间间隔。新会话第 1 轮登记，从第 100 轮注入；已有会话首次遇到第 200 轮只登记，从 300 轮开始，不补发历史检查。可改模板间隔，沿用绝对用户轮数取模，不改成登记后滚动 100 轮。

1. 存在同名全局或当前会话模板时，保留原文、启用状态、间隔，记一次“已有”登记，不再自动补。包括已关闭模板。
2. 新建模板后，编辑/改名/关闭/删除均保留；删除后的登记相当于 tombstone，重启、升级或再次开会话不复活。需恢复时由用户在面板手动创建。
3. 后增同名全局模板时，自动生成的会话模板停止注入，避免双份；全局开关和周期完全按用户配置执行。删除该全局模板后，原会话模板恢复其配置。并不自动合并/删除任何模板。
4. 任意其他名称不以模糊文本猜测同义。已有异名等价模板，请关闭自动功能或关闭生成项，自行取舍。
5. 自动项若被用户显式“设为全局”，沿用普通全局轮次规则；`evolutionAssessmentEnabled:false` 仍抑制该自动来源的模板。用户自己创建的模板不受此开关控制，需自身关闭或 `injectEnabled:false`。
6. `injectMaxEvery < 100` 时不创建，避免绕过已有部署上限。

## 持久性、升级与证据

schema v6 新增 `evolution_defaults(session_id, template_id, source, version, enrolled_turn, disposition)`，不记录任务内容、提示词历史或私密材料。`BEGIN IMMEDIATE` + 会话主键保证多连接补充幂等；模板创建与登记同事务。v1–v5 单事务迁移，原模板不改；初始化或迁移失败会回滚并关闭本次连接，保留原错误，避免失败对象泄漏数据库句柄。CLI 兼容 v6，但模板导出不包含 enrollment/tombstone。

新默认项来源为 `agent-atelier/evolution-self-assessment@2`，写入登记及模板 description；v2 仅缩窄 A2A 角色／授权路由，不改变周期。旧 v1 登记与已有模板内容、启用状态、间隔、模式保持原样；新文案只用于未登记会话，绝不自动覆盖已有模板。日志继续沿用 `prompt-template-schedule` 的模板 ID/名称/间隔与 turn；描述可被用户改写，SQLite 登记才是来源事实。注入日志不是评估完成证据，更不是迁移成功证据。

相同 turn 的耐久日志去重与进程内去重沿用原注入器。**未支持同一 DSH 会话由两个独立宿主并发执行**：本次并发保证针对 SQLite 模板补充，不声称跨宿主注入 exactly-once。技能不可用时提示词要求明确报告缺失，不自动安装或杜撰通过；这属于模型遵守的指令，并非宿主检测器。

## 停用与回滚

- 本版本功能回滚：设置 `evolutionAssessmentEnabled:false`，仅停本功能补充/自动来源注入；不删模板，不改事件提醒。全部定时注入关闭用 `injectEnabled:false`。
- 单会话关闭：面板关闭或删除生成模板，不会再补。
- 包降级至仅支持 v5 的版本前，需停止写入并使用升级前的一致 SQLite 备份恢复；不得仅改 `user_version` 或删除表冒充回滚。模板 JSON 不是完整运行态备份。回滚/部署均需单独授权，本 PR 不执行。
- 新宿主/全新数据库有独立登记。CLI JSON 只带模板／类目并保留其中的启用配置；经显式 dry-run／确认后，它能重建已删除模板（含原 ID），但不重置旧库登记，也不把登记复制到新库。在原库恢复相同 ID 后仍受自动来源总开关约束；在新库导入的行是显式用户配置，不因 description 文本变成受管理默认项。它不等于完整回退，也不能据此声称删除意图随 JSON 搬迁。
- 剪贴板分享导入是另一入口：新增项默认关闭，同名覆盖保留目标开关。不要把它与保留配置的 CLI 快照导入混为一谈。跨机迁移需另核启用策略及授权。
