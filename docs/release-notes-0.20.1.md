# v0.20.1（2026-11-21）

> 发布说明中英双语；本文同文进入 GitHub Release。

## 中文

- **「会话模板」tab 现在列出本会话的体会**（#58）：此前体会只在「全局模板」视图可见，切到「会话模板」tab 找不到自己写过的体会；现在两个 tab 都能按各自范围看到，面板按这个入口核对/编辑/删除体会不再需要绕路。

## English

- **The session-templates tab now lists the session's lessons** (#58): previously lessons appeared only in the global-templates view, so switching to the session-templates tab hid the lessons a session had written; both tabs now show their proper scope, and checking, editing or deleting a lesson from the panel no longer needs a detour.
